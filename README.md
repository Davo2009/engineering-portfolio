# Logic Gate Simulations

Built in CircuitVerse (free browser simulator) as part of Week 3 of my chip design and embedded systems roadmap.

## What I built
1. **De Morgan's first law:** NOT(A AND B) compared with (NOT A) OR (NOT B).
2. **NOT gate from a NAND:** both NAND inputs tied together.
3. **AND gate from two NANDs.**
4. **Three-input circuit:** (A AND B) OR (NOT C).



## What I learned
- NAND Gate is a universal gate

## Mistakes I made
- Used a NAND instead of an AND in the first circuit, so the two gates cancelled and the LED stayed on. Fixed by swapping the gate.
